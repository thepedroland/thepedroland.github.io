Starting on Matlab for topography analysis? Here are some tips you want to know. 
First, you have to be sure you have these two toolboxes. The Topoanalysis Kit and Topo toolbox, once you start working with them you will realize that you are using both but you are actually not sure the functions that belong to each one.
Version matters! When using example of codes from tutorials you have found in the Internet. Errors may arise due to the fact the tutorial is giving you block.of.codes that would work in a previous version of Matlab or the packages and now something changed and they don’t work anymore. Always check you are using the version you intended to! 
Matlab runs in two versions per year. First half are the .a and second half the .b.
After you update to a new version you code might not work! Be aware of that, and be sure the package versions you are using were supposed to work in the new matlab version you have.
Here, I suggest you only update your Matlab if the package asks for it! Since the change of breaking the compatibility might happen, especially when it’s a version just released!
